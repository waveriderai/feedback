# WaveRider.ai Feedback

Public feedback tracker for [WaveRider.ai](https://app.waverider.ai) — the momentum stock scanner built for serious traders.

## How to submit feedback

Use the **feedback button** (bottom-right corner) inside the app at [app.waverider.ai](https://app.waverider.ai). Your feedback is automatically posted here as an issue.

You can also [create an issue directly](https://github.com/waveriderai/feedback/issues/new).

## Categories

| Label | Description |
|-------|-------------|
| `bug` | Something isn't working |
| `enhancement` | Feature request |
| `ux` | User experience improvement |
| `beta-feedback` | Submitted via in-app feedback form |

## Response

We review all feedback and will respond directly on the issue. You'll receive an email notification when we reply.
